# Medios y sitios para la difusión de mapafiscal.es

Lista de 79 medios y sitios online españoles a los que pedir un enlace o una mención.
Las plantillas de correo están en [`plantillas.md`](plantillas.md).

## Cómo leer esta lista

- **URL**: la sección concreta donde encaja la web. Si no se pudo comprobar, se da solo el dominio.
- **Contacto**: solo el canal que el propio medio publica en su web (correo o formulario).
  Si no se encontró, pone «buscar contacto». Los correos salen de sus páginas de contacto
  o de prensa, tal como aparecían en noviembre de 2026; confírmalos antes de escribir.
- **Verificado**:
  - **sí**: la búsqueda web devolvió la sección o artículos recientes del medio sobre IRPF.
  - **no (bloqueado)**: el medio bloquea la herramienta de búsqueda que se usó. Existe y es
    conocido, pero la sección y el contacto hay que buscarlos a mano.
- **Ángulo común**: con el mismo sueldo, el IRPF cambia según el territorio. Las cifras para
  usar están en `plantillas.md` (sacadas de `web/datos/seo_comparativas.json`, ejercicio 2025).

Para cada tipo, los medios aparecen por orden de prioridad aproximada.
